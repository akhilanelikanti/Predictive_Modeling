Heart Disease Prediction Using Machine Learning

Aim:
To build a machine learning model that predicts whether a person has heart disease using medical data.

Description:
This project uses a Heart Disease dataset to predict the presence of heart disease. The dataset is first cleaned and prepared for analysis. Then, three machine learning algorithms—Logistic Regression, Decision Tree, and Random Forest—are trained and tested. Finally, the models are evaluated using accuracy, a confusion matrix, and an ROC curve to compare their performance.
